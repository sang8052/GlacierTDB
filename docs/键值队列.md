# GlacierTDB 键值/队列手册（Redis 基础能力，v1.3.2）

> 通过 `mode:redis` 在 **3309 同端口**提供 RESP 协议服务：string / list 队列、
> **BLPOP/BRPOP 阻塞弹出（v1.3.2）**、TTL、
> **SQLite 实时落盘（重启无损）**、每用户独立命名空间、内存上限与 LRU 淘汰。
> 一篮子替代 MinIO + Redis：备份 = 拷贝数据目录。

---

## 1. 端口复用与连接

一个端口 3309 承载多协议（FEATURE §0）：

| 进入方式 | 说明 |
| --- | --- |
| `mode:redis` 声明行（首选） | 连接建立后第一行为 ASCII 单行 `mode:redis`（`
` 或 `
` 结尾），网关消费后进入 RESP 栈 |
| RESP 嗅探（兜底） | 原生 redis-cli / redis-py 等无法插声明行：首字节为 `* + - : $` 即判为 RESP |
| 默认 | 静默等握手（嗅探窗口内无数据）→ MySQL（存量客户端零改动） |

嗅探窗口 `mux_sniff_ms`（默认 300ms）：高 RTT 客户端可调大；`kv.enable: false` 关闭嗅探
（纯 MySQL、连接建立零延迟）。`mode:rabbitmq` 声明行与 AMQP 魔数嗅探进入 RabbitMQ 栈（v1.3.0，
见消息队列手册）。

```bash
redis-cli -h <host> -p 3309            # 自动嗅探进入
# 或自定义客户端：
printf 'mode:redis
*2
$4
AUTH
$8
iloveyou~
' | nc <host> 3309
```

## 2. 认证与命名空间

- `AUTH <password>`：密码匹配任一账号即以该账号命名空间登录（推荐双参形式）；
- `AUTH <user> <password>`：指定账号；
- 沿用统一账号体系：host 授权（`user_hosts`）、账号锁定、登录审计（`login_attempts`）、
  防爆破计数与 MySQL 侧一致；未认证执行数据命令返回 `NOAUTH`。
- **命名空间 = 登录账号**：key 自动按用户隔离，跨用户不可见（KEYS/GET 均不可见）。

## 3. 命令集（RESP2）

| 类别 | 命令 |
| --- | --- |
| string | `GET` `SET key val [EX s\|PX ms] [NX\|XX]` `DEL` `UNLINK` `EXISTS` `APPEND` `STRLEN 不支持` |
| 计数 | `INCR` `DECR` `INCRBY` `DECRBY` |
| 批量 | `MGET` `MSET` `KEYS pattern`（glob `*`/`?`）`TYPE`；**`SCAN cursor [MATCH p] [COUNT n] [TYPE t]`（v1.3.3，单批全量返回 + 游标恒 0，`redis-cli --scan` / `scan_iter` 可用）** |
| TTL | `EXPIRE` `PEXPIRE` `TTL` `PTTL` `PERSIST`（惰性过期 + `kv.scan_interval_sec` 定期扫描） |
| list 队列 | `LPUSH` `RPUSH` `LPOP [count]` `RPOP [count]` `LLEN` `LRANGE start stop`（含负下标）；**`BLPOP key [key…] timeout` `BRPOP …`（v1.3.2 阻塞弹出）** |
| 连接/其他 | `PING` `ECHO` `QUIT` `SELECT 0` `INFO` `FLUSHDB` `COMMAND`（空应答）；**`HELLO [protover [AUTH user pass] [SETNAME name]]`（v1.3.3 最小应答：server map + `proto:2`，redis-py ≥ 8 默认 RESP3 握手可直连自动降级；`HELLO 9` 报 `NOPROTO`）** |

- **阻塞弹出（v1.3.2）**：按参数顺序扫描 key，取首个非空 list 弹出一个元素（BLPOP 左端 /
  BRPOP 右端），应答 `[key, value]` 二元数组；全部为空则阻塞等待——任一 key 被 LPUSH/RPUSH
  立即唤醒，或超时后返回空数组（RESP2 `*-1`）。`timeout` 支持小数秒，`0` = 无限等待；
  非 list 键按扫描顺序到达时返回 `WRONGTYPE`；负超时报 `ERR timeout is negative`；
- **HELLO（v1.3.3）**：应答 server map（server/version/proto/id/mode/role/modules）且 `proto` 恒为 `2`——redis-py ≥ 8 默认 `protocol=3` 的握手（`HELLO 3 AUTH default <pwd>`）不再报错，客户端自动按 RESP2 继续；`AUTH` 子参数在 HELLO 内一并完成认证（`default` 等价单密码形式）；
- 类型错误返回 `WRONGTYPE`；非整数计数返回 `ERR value is not an integer or out of range`。

## 4. 持久化与恢复

- **变更实时写 SQLite**（`<db_dir>/glacier_kv.db`，WAL）：SET/RPUSH/EXPIRE 等即时落盘；
- 内存为缓存层（全量常驻，受 `kv.max_memory_mb` 治理）；**重启无损恢复**——
  字符串、队列元素（含顺序）、TTL 剩余时间全部还原（`tests/run_all.sh` 步骤 3.5 实测）。

## 5. 内存治理

```yaml
kv:
  enable: true           # mode:redis 开关（默认开）
  max_memory_mb: 64      # 内存上限（0 = 不限）
  eviction: allkeys-lru  # allkeys-lru | volatile-lru | noeviction
  scan_interval_sec: 5   # TTL 主动扫描周期
```

- 超限写入按策略淘汰：`allkeys-lru`（全键 LRU）/ `volatile-lru`（仅带 TTL 的键）/
  `noeviction`（拒绝写入，返回 `OOM command not allowed when used memory > 'maxmemory'`）；
- 管理面热改（重启失效）：`SET KV MAX_MEMORY <mb>` / `SET KV EVICTION <policy>`。

## 6. 统计查询（kv_stats）

```sql
USE GlacierTDB;
SHOW KV STATS;
SELECT * FROM kv_stats WHERE namespace = '*';
```

| 列 | 说明 |
| --- | --- |
| `namespace` | 登录账号（`*` 为合计行） |
| `keys` / `memory_bytes` | 键数 / 估算内存占用 |
| `max_memory_mb` / `eviction` | 当前生效的上限与策略 |
| `hits` / `misses` / `hit_rate` | 命中 / 未命中 / 命中率 |
| `expired` / `evicted` | TTL 过期数 / 内存淘汰数 |
| `ops` / `uptime_sec` | 累计命令数 / 运行秒数 |

## 7. 客户端示例（redis-py）

```python
import redis
r = redis.Redis(host="10.25.250.30", port=3309, password="iloveyou~", decode_responses=True)
r.set("k", "v", ex=60)          # TTL 60s
r.rpush("q", "job-1", "job-2")  # 队列
print(r.lpop("q"))              # job-1
print(r.blpop("q", timeout=5))  # 阻塞弹出（空队列最多等 5s；超时返回 None）
```

> 单参 `AUTH <password>` 亦可；双参 `AUTH <user> <password>` 更明确（redis-py 的
> `username=` 参数）。连接即入该账号命名空间。

## 8. 已知边界

- 发布订阅、事务（MULTI）、Lua、集群协议不在本版范围（FEATURE 红线）；
- BLPOP/BRPOP 为单连接串行阻塞（与 RESP 一致）：阻塞期间该连接不能执行其他命令；
  `timeout=0` 无限等待，客户端断开后阻塞在下次 Push 唤醒（写应答失败）或超时时自然结束；
- RESP2 only：`HELLO` 应答 `proto:2`（不升级 RESP3，协议数据帧仍为 RESP2；redis-py ≥ 8 无需 `protocol=2` 即可直连）；**空值帧按协商形态（v1.3.4）**——`HELLO 3` 连接的空值应答发 RESP3 null 帧 `_`（RESP3 解析器遇 `$-1` 会按「读 -1 字节」挂死），RESP2 连接维持 `$-1`/`*-1`；
- 单值上限 64MB；`KEYS`/`SCAN` 均为全命名空间扫描（SCAN 为简化实现：单批返回、游标恒 0；生产建议配合具体前缀模式）；`HSCAN/SSCAN/ZSCAN` 无对应类型，报 unknown command。
