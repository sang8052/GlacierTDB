为无人值守的边缘而设计

SQLite 内核永不损坏 —— 单文件 + WAL，崩溃 / 掉电后已提交事务不丢，重启即恢复
写安全·读并发 —— 每库一把写锁，多库写入天然并行；读多线程限流可配
连接独占后端 —— 每客户端连接绑定一个 SQLite 连接，事务语义架构上根除错乱
防爆破自动锁 + CLI 解锁 —— 本机回环永不锁定，管理面永远进得去
底层静态加密 —— adiantum 全库加密，备份包即密文
运维极简 —— 无守护进程依赖，一个目录拷走即迁移，systemd / Docker 双支持

30 秒上手

下载即用，无需安装任何依赖。

bash — GlacierTDB 
# 下载 release（linux-amd64 / linux-arm64 / windows-amd64）
sha256sum -c SHA256SUMS
./glaciertdb-linux-amd64 -db-dir /srv/glacier/data

# mysql 客户端直连（存量工具零改动）
mysql -h 127.0.0.1 -P 3309 -uglacier -p -e "SELECT glacier_version;"

# redis 协议嗅探直接进
redis-cli -h 127.0.0.1 -p 3309 SET hello world

# 时序：建表即自动 rollup 预聚合
mysql ... -e "SELECT avg(val) FROM points
          WHERE ts > now() - INTERVAL 7 DAY
          GROUP BY series_id, time(1 HOUR);"
